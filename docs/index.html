Quick start on Linux

Download the standalone AppImage and configure USB permissions in two simple steps.

Step 1

Run the AppImage

Make the AppImage executable and launch it directly on any modern 64-bit Linux distribution:

chmod +x KeyboardStudio-x86_64.AppImage
./KeyboardStudio-x86_64.AppImage
Step 2

Install udev rules

Grant unprivileged user access to the USB HID interface without running the app as root:

sudo cp 99-keyboard-studio-mk1300.rules /etc/udev/rules.d/
sudo udevadm control --reload-rules && sudo udevadm trigger
